企业投递简历采集面板

从一家企业出发，把「发布了哪些岗位 · 谁投了简历 · 简历里写了什么」一次拿全
端口 8790 Flask + BeautifulSoup 单表多页 Excel Windows 单文件 exe

这个工具是做什么的

输入一个企业名称（支持模糊），它会顺着招聘后台的链路一路走到底，把投递简历和简历正文整成一份 Excel。

招聘后台里，想知道「某企业收到了哪些投递、投递人是什么背景」，需要手工点开企业 → 岗位 → 投递列表 → 每份简历详情， 几百份简历点下来非常费时。这个面板把整条链路自动化：企业名称模糊搜索 → 拿到企业账号 → 拉取该企业全部岗位 → 逐个岗位拉取投递简历列表 → 再逐份抓取完整简历详情 → 汇总导出。

企业名称→ 企业账号→ 岗位列表→ 投递简历→ 简历详情→ Excel
  • 企业模糊搜索：输入「宝顺」「物流有限公司」这类关键词即可命中，不用完整全称。
  • 岗位列表可单独用：选定企业后可以先只看它发布了哪些岗位、每个岗位收到多少投递。
  • 投递明细：投递人姓名、投递时间、电话 / 邮箱 / QQ（这里电话是明文，无需 OCR）。
  • 简历深度解析：基本信息、期望职位与薪资、自我描述、工作经历、教育经历、语言能力、证书、头像照片。
  • 导出可勾选：只要岗位列表 / 只要投递简历 / 两者都要，三种组合任选，文件名自动区分。
  • 并发抓取：岗位投递与简历详情都用线程池（默认 6 线程），500+ 份简历约 1 分钟抓完。

接口链路（全部实测可用）

登录后台 Cookie 即可，无需前端网站 Cookie。四个关键接口串起整条流程。

环节接口说明
① 企业模糊搜索 GET /Enterprise/GetCompanyListData
?keyword=关键词&keyType=1&openSource=0		 keyType=1 才是模糊搜索；keyType=0 表示不筛选，会返回全量企业
② 岗位列表 GET /Post/GetYZJobList?key={企业username} 兼职岗位走 /Post/GetJZ_YZJobList
③ 岗位投递简历 GET /Post/GetSendJlList
?jobid={岗位id}&istj=-1&infotype=1		 分页返回：投递人、时间、电话、邮箱、QQ、姓名、简历ID
④ 简历详情 GET /Post/JlEdit?source=1&jlid={简历id} 服务端渲染完整简历表单，后台 Cookie 即可拿到全部字段
为什么不用前台页面？前台简历页（www.hbtc.ccoo.cn/post/qiuzhi/{id}x.html）需要前台登录， 匿名或后台 Cookie 只会返回登录页。而后台的简历编辑页 /Post/JlEdit 用后台 Cookie 就能拿到全部内容， 所以走这条路线。导出时仍会生成前台简历链接，方便人工复核。

解析要点

  • 自我描述是富文本，存在 <input id="text_merecord"> 的 value 里，含 <br> 等 HTML，导出前会清洗成纯文本。
  • 求职状态取 radio name=jlstate 的 title；个人亮点取 checkbox name=liangdian（可多个）。
  • 工作经历取 ul.js-work-list li.item，其中结束年 value='0' 表示「至今」。
  • 证书必须要求证书名非空才收录（日期控件带占位默认值，否则会写入假数据）。
  • 页面里的 <ul> 总含 1 个供前端克隆的空模板项，解析时会过滤掉。

使用流程

① 登录 / 填 Cookie

在配置区填后台账号密码，或粘贴 Cookie，点「测试」验证。

② 搜索企业

输入企业名称关键词做模糊搜索，从结果里选中目标企业。

③ 取岗位列表

可选：先拉取该企业的岗位列表，确认要采集哪些岗位的投递。

④ 抓取投递与简历

点开始抓取，面板并发拉取投递列表与每份简历详情，进度实时显示。

⑤ 勾选导出内容

选择「仅岗位列表 / 仅投递简历 / 两者都要」，选好目录导出 Excel。

⑥ 查看结果

Excel 冻结首行 + 自动筛选 + 超链接，岗位名/简历名可直接点开对应网页。

方式一：直接运行 exe（推荐）

到 Release 页面下载 ResumeCollector-v1.0.0-windows-x64.exe，放到单独目录双击运行，浏览器会自动打开 http://127.0.0.1:8790。

方式二：源码运行

# 1) 安装依赖
pip install flask requests beautifulsoup4 lxml openpyxl

# 2) 准备配置（首次，必须有 config.json，否则 Cookie 为空会返回登录页）
cd src
copy config.example.json config.json    # 然后填入账号/密码/Cookie

# 3) 启动
python -X utf8 面板.py
# 浏览器自动打开 http://127.0.0.1:8790

重新打包 exe

pip install pyinstaller
cd src
python 打包exe.py
# 产物：dist/企业投递简历采集面板.exe
注意：首次运行务必先把 config.example.json 复制为 config.json 再启动。 若 config.json 不存在或 Cookie 为空，后台会返回登录页 HTML，脚本解析 JSON 时会报 JSONDecodeError。

常见问题

企业搜不到怎么办？

换成企业全称里的关键片段，例如「宝顺」「物流有限公司」。如果关键词太短可能命中很多家，面板会列出结果让你挑选。

为什么有些岗位投递数是 0？

该岗位确实没有收到投递，属正常情况；导出时仍会保留岗位列表。

改了代码后测试拿到的还是旧数据？

多半是端口被上一轮的旧进程占着，新进程绑定失败静默退出。用 netstat -ano | findstr :8790 找到 PID 结束掉，再重启。

电话需要 OCR 吗？

不需要。这个面板拿到的投递人电话是明文（与「简历库」列表接口不同，那里才是图片）。
