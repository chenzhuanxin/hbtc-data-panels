城市中国平台数据面板

city-data-panel ｜ 端口 8787

一键抓取招聘后台 7 个类目的全量数据，自动识别电话图片并转文字，按参考格式导出 Excel。

  • 7 类目全覆盖：订单管理 / 全职岗位 / 兼职岗位 / 企业库 / 会员企业 / 简历库 / 注册用户
  • base64 图片电话自动 OCR（RapidOCR 离线识别，无需联网）
  • 类目勾选导出：单类目 = 一个 xlsx，多类目 = 自动打 zip 包
  • 保留全部字段，次要列自动隐藏；非法字符自动清洗
  • 并发分页抓取，7 类目共 9.8 万条也能快速拉完

企业投递简历采集面板

resume-panel ｜ 端口 8790

按企业名称出发，顺着 企业 → 岗位 → 投递简历 → 简历详情 一链到底，输出单表多页 Excel。

  • 企业名称模糊搜索，选企业后可单独查该企业的岗位列表
  • 岗位投递明细：投递人、时间、联系方式（明文电话/邮箱/QQ）
  • 简历内容深度解析：基本信息、期望职位薪资、自我描述、工作/教育经历、语言与证书
  • 导出可勾选：仅岗位列表 / 仅投递简历 / 两者都要
  • 并发抓取 6 线程，500+ 份简历详情约 1 分钟抓完

使用方式

两种方式选其一：直接跑 exe，或用源码启动。

1

下载 exe

到 Release 页面下载对应的 .exe 文件，放到任意目录（建议单独建一个文件夹）。

2

双击启动

双击 exe，控制台窗口会自动打开浏览器面板；关闭窗口即停止服务。

3

填写账号 / Cookie

在面板里填入后台账号密码，或直接粘贴登录后的 Cookie，点「测试」验证有效性。

4

抓取并导出

选择类目 / 企业后开始抓取，完成后勾选需要的类目导出到指定目录。
