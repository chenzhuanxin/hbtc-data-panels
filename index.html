城市中国 · 湖北通城网｜招聘频道数据工具

两套采集面板 + 一个综合版，一套招聘数据工作流

针对 城市中国 · 湖北通城网（hbtc.ccoo.cn） 招聘后台打造的本地数据工具： 一款把平台 7 大类目数据（含图片电话 OCR 与完整简历字段）整表导出 Excel， 一款顺着「企业 → 岗位 → 投递简历 → 完整简历」把投递明细一网打尽， 还有一个把两者装进同一个 exe 的综合面板（一份配置、一个端口、一个门户）。 均为 Python + Flask 本地服务 + 浏览器界面，打包为 Windows 单文件 exe，双击即用。

Windows 单文件 exe 本地运行 · 数据不上传 后台全量字段 Excel / ZIP 导出 离线 OCR 全并发提速

v2.0：详情抓取全面切换后台编辑页

不再抓前台网站、不再需要前台 Cookie；简历/岗位/企业/用户全量字段都从后台编辑页取。

四项变化

① 不需要前台 Cookie——简历正文改从后台编辑页 /Post/JlEdit 拿（字段比前台更全）； ② 新增总后台 Cookie——仅「注册用户」全量字段需要（user_set.asp，纯文本无需 OCR），可留空； ③ 速度大幅提升——后台编辑页无前台 nginx WAF，去掉令牌桶限速/请求间隔，全并发抓取； ④ OCR 仍保留——列表里的电话图片照常离线识别。

字段空缺 ≠ 抓取失败。200 份全量成功后的真实填充率：姓名/性别/年龄/自我描述详情 100%、学历 99%、工作经历 1 55%、头像 53%、现居地 45%、 教育经历 1 37%、获得证书 1 15%、语言能力 1 13%。求职者没填哪一项，后台表单里本身就没有那个区块。

使用方式

两种方式选其一：直接跑 exe，或用源码启动。

1

下载 exe

到 Release 页面下载对应的 .exe 文件，放到任意目录（建议单独建一个文件夹）。

2

双击启动

双击 exe，控制台窗口会自动打开浏览器面板；关闭窗口即停止服务。

3

填账号 / Cookie

填入后台账号密码或后台 Cookie（管类目、投递列表与简历/岗位/企业详情）。若要注册用户全量字段，再粘贴总后台 www.admin.ccoo.cn 的 Cookie（可留空），点「测试」验证。

4

抓取并导出

选择类目 / 企业后开始抓取，完成后勾选需要的类目或工作表导出到指定目录。

v2.0 不需要前台 Cookie：简历/岗位/企业详情改从后台编辑页（JlEdit / JobEdit / CompanyAdd）抓取， 用户全量字段从总后台 user_set.asp 抓取（需总后台 Cookie，纯文本无需 OCR）。后台无 WAF，全并发提速。
